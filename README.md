# Full-Stack Web Application (Python + Django + React)

A comprehensive, end-to-end full-stack web application designed to connect a high-performance backend database with a dynamic, responsive user interface. This repository serves as a practical demonstration of my engineering workflows and modular system design.

## 🚀 Core Technologies Used
* **Frontend:** React.js, JavaScript (ES6+), HTML5, CSS3, Bootstrap/Tailwind.
* **Backend:** Python, Django REST Framework, MVC Architecture.
* **Database & Tools:** SQL/PostgreSQL, Git, JSON Web Tokens (JWT).
* **System Edge:** Optimized with basic server routing protocols leveraging my background in computer hardware engineering.

## ✨ Key Features Built
* **User Authentication:** Implemented a secure registration, login, and token-based logout pipeline using Django's security metrics.
* **REST API Integration:** Constructed clean API endpoints to handle smooth CRUD (Create, Read, Update, Delete) operations between the server and the UI.
* **Dynamic Frontend Dashboard:** Built interactive React components to display live database assets without full-page reloads.
* **Hardware System Synchronization:** Configured light system automation scripts to track runtime efficiency and data packet parsing.
